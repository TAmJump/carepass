# Care Support Pass

> 100円で、社会の支え方を変える。

Care Support Pass は、月100円から参加できる**月額会員サービス**です。
飲食店・薬局・ドラッグストアなどの提携店優待を利用でき、売上の一部は先輩世代の住まい支援に活用されます。

## 中心思想

Care Support Pass は、**高齢者支援ではなく、社会の恩返しを仕組みにする事業**です。

社会をつくり、家族を守り、地域を支えてきた人たちが、年齢を重ねたその先で、安心して暮らせる場所を失わない社会をつくる。

参加する人は、月100円から。生活が少し得になる。地域のお店に人が流れる。その一部で、先輩世代の住まいが守られる。

## 4つの価値原則

1. **税金だけに任せない** — 使い道が見える100円をつくる
2. **支援する人にも価値がある** — 参加する人の生活にもメリットがある仕組み
3. **守る対象ではなく、受け継ぐ存在** — 先輩世代を社会の負担ではなく、若い世代の未来として見る
4. **仕組みになれば、社会を動かせる** — 100万人なら毎月1億円の支援原資

## 法的注記

- Care Support Pass は寄附ではなく、月額会員サービスです。
- 提携店優待は各店舗が独自に提供する割引であり、Care Support Pass が金銭的価値を発行・販売するものではありません。
- 会費は寄附金ではありません。寄附控除を希望される方には、NPO・公益財団等を通じた寄附窓口をご案内します。
- 処方薬・保険調剤の自己負担分への割引提供は行いません。
