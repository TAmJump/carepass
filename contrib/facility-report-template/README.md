# Care Support Pass / 月次活動報告書テンプレート

このディレクトリは Care Support Pass にご参加いただいている**介護施設のご担当者様**にお渡しする、月次活動報告書 HTML テンプレートの **公式版** です。

## なぜ施設のサイトで公開するのか

Care Support Pass (CSP) は、月次活動報告書の本文を **CSP のサイト上には置かず、各施設の自社サイトで公開していただく** 方針を取っています。

理由:

- **施設のブランドで届けたい**: 入居者や家族に向けたメッセージは、施設の声で届くべきです
- **編集の自由度を確保**: テキスト・写真・レイアウトを施設側で自由に追加・変更できます
- **CSP は橋渡し**: 支援者を施設の活動につなぐリンク・統計・課金だけを担当します

CSP 側は、公開された報告書の **URL とステータスのみ** を管理します。

## 設置手順 (3ステップ)

### Step 1. テンプレートを複製する

`template.html` を月ごとに複製して、ファイル名を **`YYYY-MM.html`** (4桁年-2桁月) にしてください。

```
template.html  →  2026-06.html
                  2026-07.html
                  2026-08.html
```

`assets/css/report.css` は1つだけ用意し、複数月で共有してください。

### Step 2. 自社サイトの所定のディレクトリにアップロード

CSP の施設ダッシュボードで設定する **「報告書 Base URL」** に対応するディレクトリに配置します。

例: 報告書 Base URL を `https://example.com/carepass` と設定した場合:

```
https://example.com/carepass/
├─ 2026-06.html      ← 月次の HTMLファイル
├─ 2026-07.html
├─ 2026-08.html
└─ assets/
   └─ css/
      └─ report.css  ← 共通スタイル (1個でOK)
```

**URL のフォーマットを変えないでください**。CSP は `{Base URL}/{YYYY-MM}.html` で到達性を自動確認します。

### Step 3. CSP のダッシュボードに URL を登録

- [https://carepass.115en.com/facility-dashboard.html](https://carepass.115en.com/facility-dashboard.html) にログイン
- 「月次活動報告書」タブ → 対象月を選択 →「この月の報告書を登録」
- ステータスが `published` になれば公開完了です。会員のマイページに表示されます

## テンプレートの構成

`template.html` には以下のセクションがあります。**不要な部分は削除して構いません**。

| セクション | 用途 |
|---|---|
| `.hero` | タイトル・対象月・前書き |
| `.kpi-section` | 数字で見る今月 (支援者数・支援額など) |
| `.photos-section` | 今月のひとこま (写真3枚) |
| `.body-section` | 今月のできごと・使途報告・来月の予定 |
| `.message-section` | 施設長メッセージ (引用ブロック) |
| `.report-footer` | 施設情報・CSPクレジット |

写真は `<figure><img src="..."><figcaption>...</figcaption></figure>` で差し替え。
HTMLが書ける担当者がいない場合、運営にご相談いただければ、ご支給いただいた写真と原稿をテンプレートに流し込んでお渡しします。

---

## 公開済の報告書を撤回したい場合

1. **ファイルは削除しない** (CSP の到達性チェックが「broken」になるため)
2. CSP の施設ダッシュボード → 該当の月の「撤回」ボタンを押す
3. ステータスが `retracted` になり、会員からは見えなくなります
